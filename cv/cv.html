Profile

Full-stack engineer with more than ten years building reliable, scalable web applications across e-commerce, mobility, SaaS and marketing technology. Equally deep in two backend stacks, Laravel and Node.js, paired with Vue or React, and with Filament, Nova or Backpack for admin work.

Most of my architecture work comes down to domain-driven design and CQRS: drawing the boundaries in a tangled monolith so it can be scaled, observed and changed one piece at a time. When a workload outgrows PHP or Node I move that specific path to Go or Rust and leave the rest alone. When a product needs to leave the browser, I ship it in React Native or Flutter on the same API.

Alongside the code I lead teams: setting the architecture, keeping it intact through code review, mentoring developers into owning a domain, and turning loose requirements into specifications a team can build from.
